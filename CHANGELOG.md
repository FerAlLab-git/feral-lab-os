# Changelog

All notable changes to the `decision-modeling` plugin are recorded here. Versions follow
[Semantic Versioning](https://semver.org/). The version in
`plugins/decision-modeling/.claude-plugin/plugin.json` is what Claude Code uses to detect an
update, so every release changes it and adds an entry below.

## [0.1.0] - 2026-11-03

### Added

- `dm-calibration`: setting up, extending and debugging model calibrations, with references
  on likelihood choice, the PRE-CISE pre-calibration workflow, non-identifiability and
  parallelization.
- `model-code-review`: reviewing R decision-model code for correctness, reproducibility and
  computational efficiency.
- `lab-conventions`: FerAl Lab coding and naming conventions, based on the DARTH coding
  framework. Project folder layout lives in
  [FerAlLab-git/project-template](https://github.com/FerAlLab-git/project-template).
